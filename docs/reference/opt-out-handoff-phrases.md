# Angry Opt-Out & Handoff Phrases (Indian Languages)

Oct 9, 2026 · @Raja

## How to read this

Every language lists the same 10 phrases in the same order, so each number carries the same intent across languages.

| Phrase numbers | Intent | Agent action |
| --- | --- | --- |
| 2, 5, 9 | Human handoff | Pause AI (`ai_paused = true`), notify owner, confirm a person will reply |
| 1, 3, 4, 6, 7, 8, 10 | Opt-out | Set `opted_out = true`, send one confirmation, block all outbound messages |

## Usage notes

- Use these as few-shot examples and test cases for LLM intent classification, not for exact keyword matching. Spelling in Tanglish, Manglish and Hinglish varies a lot in real chats (for example venam / vendam / venaam).
- Have a native speaker check the Telugu, Kannada, Bengali, Marathi, Gujarati and Punjabi lines before treating them as final test data.
